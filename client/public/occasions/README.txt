Shop by Occasion — tile images
================================

Put one photo for each occasion in THIS folder, using these exact file names
(all lowercase, .jpg):

    formal.jpg
    casual.jpg
    wedding.jpg
    party.jpg
    business.jpg
    festive.jpg
    cocktail.jpg
    traditional.jpg

Image guidelines
----------------
- Shape: portrait (taller than wide). The tiles are 3:4.
- Recommended size: about 600 x 800 pixels (or larger at the same 3:4 ratio).
- Format: .jpg is expected. If you must use .png or .webp, also update the
  file names in client/src/pages/Home.jsx (the OCCASIONS list).
- Keep each file reasonably small (under ~300 KB) so the home page loads fast.

Until you add a real photo, that tile automatically shows a temporary
placeholder image instead of a broken-image icon.
